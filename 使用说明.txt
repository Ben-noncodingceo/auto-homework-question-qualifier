======================================================
作业题目质量评估系统 - 纯前端版本
======================================================

🎉 无需安装任何软件！直接在浏览器中运行！

使用方法：
==========

方法一：直接双击打开（推荐）
---------------------------
1. 找到文件：homework_analyzer.html
2. 双击打开（会在默认浏览器中打开）
3. 开始使用！

方法二：拖拽到浏览器
------------------
1. 找到文件：homework_analyzer.html
2. 拖拽到浏览器窗口
3. 开始使用！


功能特点：
=========
✅ 纯前端运行，无需安装 Python
✅ 无需启动服务器
✅ 跨平台：Windows、macOS、Linux 都可用
✅ 支持离线使用（需要联网调用 AI API）
✅ 所有文件处理都在本地浏览器中完成
✅ 安全：文件不会上传到任何服务器（除了发送文本给 AI API）


使用步骤：
=========

1. 上传 PDF 文件
   - 点击上传区域或拖拽 PDF 文件
   - 支持 10MB 以内的 PDF

2. 配置 API
   - 选择 DeepSeek（推荐）或 OpenAI
   - 输入你的 API 密钥

3. 开始处理
   - 点击"开始处理"按钮
   - 等待 30-60 秒

4. 查看结果
   - LaTeX 代码（可下载、可复制）
   - 每道题的难度评分（0-5 分）
   - 每道题的 5 个知识点标签


API 密钥获取：
============

DeepSeek（推荐 - 便宜）：
-----------------------
1. 访问：https://platform.deepseek.com/
2. 注册账号
3. 创建 API 密钥
4. 费用：约 ¥0.001/千字

OpenAI（贵一些）：
----------------
1. 访问：https://platform.openai.com/
2. 注册账号
3. 创建 API 密钥
4. 需要国际信用卡


技术说明：
=========
- 使用 PDF.js 读取 PDF 文件
- 使用 JavaScript Fetch API 调用 AI
- 完全在浏览器中运行
- 不需要 Node.js、Python 或任何后端


浏览器要求：
==========
支持所有现代浏览器：
✅ Chrome（推荐）
✅ Edge
✅ Firefox
✅ Safari
✅ Opera


故障排查：
=========

问题：API 调用失败
解决：
1. 检查 API 密钥是否正确
2. 检查网络连接
3. 确认 API 余额充足

问题：PDF 无法读取
解决：
1. 确认是 PDF 格式
2. 确认文件没有加密
3. 确认文件小于 10MB

问题：页面无法打开
解决：
1. 更新浏览器到最新版本
2. 尝试其他浏览器
3. 检查是否启用了 JavaScript


文件说明：
=========
homework_analyzer.html - 唯一需要的文件，双击打开即可使用

其他文件（可选）：
app.py - Python 后端版本（不需要使用）
templates/ - 后端版本的模板（不需要使用）
src/ - 后端版本的代码（不需要使用）


优势对比：
=========

纯前端版（homework_analyzer.html）：
